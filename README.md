# Apple Season Tracker

Track apple sales, orchard expenses and profit for each season. Built with plain HTML, CSS and JavaScript.

## Features
- Sales: variety, boxes, rate per box, buyer or mandi
- Expenses by category
- Profit or loss, boxes sold and average rate per box
- Reports by variety and category
- JSON backup and restore, CSV export
- Mobile friendly, dark mode, works offline after the first visit

## Run
Host it with GitHub Pages: **Settings > Pages > Deploy from a branch > main / root**.

Locally: `python -m http.server`, then open http://localhost:8000

## Data
Records stay in the browser (localStorage). Nothing is uploaded. Clearing site data erases them, so keep backups.
